7. CLIMATE TIME MACHINE
====================================================

Create an impressive interactive historical
replay feature called:

CLIMATE TIME MACHINE

This must be a major highlight of the dashboard.

Interface:

- Select a historical year.
- Select an available disaster category.
- For cyclones, select a recorded storm.
- Display the event on the India map.
- Include a chronological timeline.
- Include Play, Pause, Restart and Step controls.
- Include playback speed settings.
- Display the current timestamp.
- Display source and event metadata.

For cyclone replay:

1. Request historical cyclone records.
2. Let users select a real storm.
3. Fetch its chronological track.
4. Plot the full verified route.
5. Animate a marker along recorded track points.
6. Update timestamp and measurements.
7. Let users pause at any observation.
8. Show the storm path clearly against India.

Use source-record timestamps.

If visual interpolation is added, make it
clear that intermediate positions are visual
estimates, not additional observed data.

A suitable demonstration target is Cyclone
Fani (2019), provided the backend confirms
the necessary records are available.

For floods and landslides:

Support timeline-based display of available
historical event records.

For rainfall:

Support switching among available years
or historical periods.

Do not invent missing records or create
fictional animation paths.
